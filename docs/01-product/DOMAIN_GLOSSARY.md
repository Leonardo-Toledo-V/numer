# Glosario del dominio

Estado: vocabulario inicial propuesto. Responsable: product-analyst.

| Término | Significado de trabajo | Distinción necesaria |
|---|---|---|
| Cuenta financiera | Registro de un lugar o posición donde se representa dinero o deuda | Tipo y relación con crédito pendientes |
| Tarjeta | Instrumento asociado a una cuenta | No confundir instrumento con dinero adicional |
| Movimiento | Hecho financiero registrado que participa en el historial | No es una estimación futura |
| Ingreso | Entrada clasificada como ingreso según reglas de producto | Una transferencia propia no es ingreso global |
| Gasto | Consumo o salida reconocida como gasto | Un pago de deuda no vuelve a reconocer la compra |
| Transferencia | Movimiento entre cuentas del mismo propietario | Conserva total en una misma moneda, sin comisiones |
| Devolución | Reversión económica de un gasto o parte de él | No necesariamente equivale a ingreso nuevo |
| Saldo inicial | Valor de partida con fecha de referencia | Su incorporación al historial debe decidirse |
| Saldo registrado | Resultado de hechos registrados según reglas de cálculo | No incluye proyecciones como hechos |
| Saldo disponible | Cantidad utilizable bajo la definición de producto | Puede diferir de saldo registrado o crédito disponible |
| Deuda | Obligación pendiente de pago | No confundir límite de tarjeta con patrimonio |
| Fondo de ahorro | Dinero destinado a ahorrar | Puede ser cuenta real o apartado; pendiente |
| Meta de ahorro | Objetivo cuantificado, con o sin fecha | No constituye un activo adicional |
| Presupuesto | Límite o plan por periodo y categoría | No modifica por sí mismo el saldo |
| Recurrencia | Regla que prevé eventos repetidos | No prueba que el cobro ocurrió |
| Proyección / forecast | Estimación calculada a partir de datos y supuestos | No garantía ni movimiento registrado |
| Corte | Cierre de un periodo de tarjeta | Distinto de vencimiento o fecha de pago |
| Vencimiento | Fecha límite de una obligación | Reglas para días inexistentes pendientes |
| Timeline | Vista cronológica del historial | Diferente del calendario de eventos previstos |
| Snapshot | Resumen de saldo en un instante | Si se adopta, debe reconciliarse con la fuente de hechos |
| Idempotencia | Repetir una misma operación no cambia otra vez su efecto | Distintas operaciones legítimas no se deben fusionar |

Ante ambigüedad, producto actualiza el glosario y la regla relacionada antes de que otros roles implementen significados diferentes.
