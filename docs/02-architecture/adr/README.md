# Registro de decisiones de arquitectura

Responsable: architect. Estado: no hay ADR aprobado.

Crear archivos `ADR-001-titulo.md`, con numeración estable, usando [la plantilla de decisión](../../templates/DECISION.md). Registrar contexto, alternativas, consecuencias, estado y evidencia de resolución. No modificar retrospectivamente una decisión para ocultar que fue sustituida.

Primeros temas candidatos: modelo de ledger, representación monetaria, sesión y acceso a datos, atomicidad e idempotencia, y separación entre movimientos y proyecciones. La selección del stack ya está recogida como requisito del usuario en DEC-001; no hace falta inventar una evaluación previa para justificarla.
