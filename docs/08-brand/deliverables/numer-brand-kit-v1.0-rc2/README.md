## Activos

- `wordmark/`: nombre dibujado SVG y PNG transparente, en petróleo, porcelana y grafito.
- `symbol/`: monograma SVG y PNG transparente, mismas tres tintas.
- `icon/`: SVG y PNG de 16/32/48/64/256 px, combinación original aprobada.
- `favicon/`: ICO con 16/32/48 px.
- `typography/`: Manrope Regular, Medium y Semibold originales, con licencia SIL OFL.
- `guide/`: manuales, contexto confirmado y handoff.

La n del monograma conserva su dibujo aprobado; la nueva composición del nombre queda para valoración visual. Las tintas, mensajes y reglas ampliadas tienen visto bueno BR-A07. Los PNG de nombre tienen 1332 × 280 px y los de símbolo 400 × 400 px; el SVG sigue siendo la fuente para otras exportaciones.

El nombre integrado contiene contornos y transformaciones vectoriales. No recomponerlo con una n tipográfica ni modificar la silueta del símbolo.

`manifest.json` contiene ruta, tamaño y SHA-256 de cada archivo excepto el propio manifiesto. `verification.json` resume la revisión. No se incluyen logos bancarios, propuestas gráficas descartadas, credenciales ni archivos de Sites. No se otorga una licencia abierta sobre la identidad Numer; la licencia incluida corresponde únicamente a Manrope.
